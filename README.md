# EU PPWR Packaging Empty-Space (<=50%), Recyclability Grade & GSM-to-PT Calculator

Live interactive tool: **https://alicewu1235647.github.io/eu-ppwr-packaging-calculator/**

Open-source browser calculator for structural packaging engineers and EU importers preparing custom paperboard boxes and corrugated e-commerce mailers for **Regulation (EU) 2025/40 (PPWR)**:

1. **Article 24 Maximum Empty-Space Ratio (`<= 50%`)**: Calculates `[(V_internal - V_product) / V_internal] * 100%` (accounting for the rule that bubble wrap, air cushions, shredded paper, and EVA foam void blocks count as empty space).
2. **Article 6 Design-for-Recycling Performance Grades (`A >= 95%`, `B >= 80%`, `C >= 70%`)**: Evaluates mono-fibre paperboard mass share against wet BOPP film lamination, aqueous dispersion varnish, and non-separable plastic/foam components.
3. **GSM to Caliper (`mm` & `PT`) Conversion Table**: Reference thicknesses for 300–400 gsm virgin C1S ivory folding boxboard, 1200–1500 gsm rigid greyboard, and E-flute corrugated mailers.
